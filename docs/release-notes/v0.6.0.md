# AgentScope v0.6.0

AgentScope v0.6.0 is the first session-import release. It adds a permissive Session JSON adapter for Claude/Codex-style tool-call exports, so agent session logs can be turned into AgentScope traces without hand-writing JSONL.

## Highlights

- **Session JSON adapter.** `npm run agentscope -- import-session <input.json>` imports a JSON array or a JSON object containing tool-call entries.
- **Claude/Codex-style field mapping.** The adapter recognizes common fields such as `tool`, `tool_name`, `input.file_path`, `input.command`, `output`, `result`, and `patch`.
- **Automatic action normalization.** Read, edit, command, test pass/fail, and summary-like tool calls are mapped to AgentScope action types.
- **Generated run metadata.** The adapter infers agent, status, trust score, files changed, command count, branch, cost, and duration where possible.
- **Example session.** `examples/agent-session.json` provides an anonymized Claude Code-style session that imports and validates out of the box.
- **Dedicated guide.** `docs/session-json.md` documents accepted input shapes, field mapping, action mapping, generated metadata, and limitations.

## Try it

```bash
# Import the example session
npm run agentscope -- import-session examples/agent-session.json

# Validate the generated trace
npm run agentscope -- validate .agentscope/*.trace.json

# View in the Web UI
npm run dev
# Then import the generated trace via the Import button or drag-and-drop
```

## Accepted input shape

The adapter accepts either:

- a JSON array of tool-call entries
- a JSON object with one of these array fields: `events`, `messages`, `actions`, `entries`, `toolCalls`, `tool_calls`, or `steps`

This keeps the MVP flexible while real Claude/Codex export formats continue to evolve.

## Known limitations

- **Best-effort mapping.** This is a permissive importer, not a native parser for every Claude Code or Codex export shape.
- **Unrecognized entries are skipped.** If an entry does not look like a supported tool call, AgentScope leaves it out of the generated trace.
- **No private log access.** The adapter only reads files explicitly passed to the CLI.
- **Native adapters are still planned.** Future Claude Code and Codex native adapters can preserve richer metadata once stable export samples are available.
