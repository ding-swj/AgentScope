# AgentScope v0.5.0

AgentScope v0.5.0 is the PR workflow release. It turns trace files into Markdown pull request summaries, so reviewers can see what an agent read, changed, ran, failed, and verified without leaving GitHub.

## Highlights

- **PR summary comments.** `npm run agentscope -- summarize --input <trace.json>` creates or updates one AgentScope comment on a pull request when run in GitHub Actions.
- **Local dry-run mode.** Add `--dry-run` to render the exact Markdown locally without calling the GitHub API.
- **Multi-run summaries.** Trace files with multiple runs render a compact overview table followed by per-run sections.
- **Verification details.** Command, failed-test, and passed-test actions are grouped into a verification section with captured output.
- **No duplicate comments.** AgentScope uses the hidden `<!-- agentscope-summary -->` marker and updates the previous bot comment on repeated workflow runs.
- **Zero new dependencies.** The CLI uses Node's built-in `fetch` and the workflow-provided `GITHUB_TOKEN`.

## Try it locally

```bash
# Render a Markdown summary in the terminal
npm run agentscope -- summarize --input examples/auth-fix.trace.json --dry-run
```

## Use it in GitHub Actions

```yaml
permissions:
  contents: read
  issues: write
  pull-requests: write

steps:
  - uses: actions/checkout@v4
  - uses: actions/setup-node@v4
    with:
      node-version: 20
      cache: npm
  - run: npm ci
  - run: npm run agentscope -- record -- npm run lint
    continue-on-error: true
  - run: npm run agentscope -- validate .agentscope/*.trace.json
    if: always()
  - run: npm run agentscope -- summarize --input .agentscope/*.trace.json
    if: always() && github.event_name == 'pull_request'
    env:
      GITHUB_TOKEN: ${{ secrets.GITHUB_TOKEN }}
```

See [`examples/github-actions/record-trace.yml`](../../examples/github-actions/record-trace.yml) for a full copy-pasteable workflow.

## Permissions

The summary step uses GitHub's issue comments API because pull request conversation comments are represented as issue comments:

- `contents: read` to check out the repository
- `issues: write` to create or update the PR conversation comment
- `pull-requests: write` for PR workflow compatibility

No external LLM service is called. The summary is generated entirely from the trace JSON file.

## Known limitations

- **Summaries depend on trace quality.** AgentScope summarizes the actions already present in the trace; it does not infer missing file reads, edits, or commands.
- **PR comments only.** v0.5.0 posts one conversation comment, not inline review comments.
- **GitHub Actions context required for posting.** Non-dry-run mode expects `GITHUB_TOKEN`, `GITHUB_REPOSITORY`, and a pull request event or pull request ref.
- **No package publish yet.** The documented command is still `npm run agentscope -- ...`; npm `npx agentscope ...` publishing remains future work.
