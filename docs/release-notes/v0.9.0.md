# AgentScope v0.9.0

AgentScope v0.9.0 is a PR review polish release. It adds a compact review checklist to every generated PR summary, making v0.8.0's trace quality warnings easier to act on: v0.8.0 finds suspicious patterns, and v0.9.0 presents the review answer at a glance.

## Highlights

- **Compact review checklist.** `summarize` now renders a `### Review Checklist` section above the actions table.
- **Code changes.** Shows whether the run edited files, using run-level `filesChanged` metadata.
- **Verification.** Shows how many verification commands were run across command and test actions.
- **Failures recovered.** Shows whether failed tests were followed by later passing tests.
- **High-risk evidence.** Shows whether high-risk edits have evidence notes.
- **CLI test coverage.** 21 tests now cover summary rendering, checklist happy paths, edits without verification, and failed tests without recovery.

## Try it

```bash
npm run agentscope -- summarize --input examples/auth-fix.trace.json --dry-run
```

The generated Markdown now includes a compact checklist before the actions table:

```markdown
### Review Checklist

| Check | Status |
| --- | --- |
| Code changes | 4 file(s) edited |
| Verification | 3 command(s) run |
| Failures recovered | 1 failure(s) -> 1 passing test(s) |
| High-risk evidence | All high-risk edits have evidence |
```

## Why this matters

Reviewers should not have to scan every action row just to decide whether an agent run is worth trusting. The checklist lets a reviewer understand the core run quality in a few seconds: whether code changed, whether verification happened, whether failures recovered, and whether high-risk edits included evidence.

## Known limitations

- **Overview only.** The checklist summarizes run-level signals; it does not replace the action table or per-action evidence.
- **Depends on run metadata.** Code changes use `run.filesChanged`, not a fresh count of `edit_file` actions.
- **No artifact links yet.** PR summaries do not yet link uploaded trace artifacts.
- **No inline review comments.** The summary remains one PR conversation comment.
