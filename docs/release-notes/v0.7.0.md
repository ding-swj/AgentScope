# AgentScope v0.7.0

AgentScope v0.7.0 is a CLI reliability release. It adds a lightweight test suite for the CLI, covers important failure paths, and makes recorded traces validate themselves before they are written.

## Highlights

- **CLI smoke tests.** `npm test` now runs Node's built-in test runner against the core CLI flows: `import-jsonl`, `import-session`, `validate`, `summarize --dry-run`, and `record`.
- **CI test coverage.** The GitHub Actions CI workflow now runs `npm test` alongside lint and build.
- **Recorder validation check.** `record` now validates the generated trace object before writing it. If the generated trace is invalid, AgentScope prints a validation warning while still preserving the recorded command's exit code and trace output.
- **Recorder success and failure coverage.** Tests now lock in both successful and failing recorded commands, including failure trace output, `failed` status, `test_failed` action type, stderr capture, and exit code evidence.
- **CLI error-path coverage.** Tests now cover invalid JSONL, empty or unsupported session imports, missing GitHub credentials for PR comments, missing trace files, wrong schema versions, and empty `runs` arrays.

## Try it

```bash
# Run CLI tests
npm test

# Record a passing command
npm run agentscope -- record -- echo hello

# Validate a trace
npm run agentscope -- validate examples/auth-fix.trace.json
```

## Why this matters

AgentScope's CLI is the path from real agent work to inspectable traces. v0.7.0 makes that path safer by checking generated traces, preserving behavior on failures, and adding regression coverage around the places users are most likely to hit rough edges.

## Known limitations

- **No new UI features.** This release focuses on CLI reliability and test coverage.
- **No native adapter yet.** Session JSON remains a permissive importer; native Claude Code and Codex adapters are still planned.
- **Recorder validation warnings do not fail the recorded command.** This is intentional so the CLI preserves the command's real exit code.
