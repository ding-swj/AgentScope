# AgentScope v1.0.0

AgentScope v1.0.0 is the first stable release: a complete trace layer for AI coding agents, from local recording and validation to visual inspection and PR review summaries.

## Highlights

- **Two months of iteration.** From v0.1.0 to v1.0.0, AgentScope shipped 13 GitHub releases and now has 30 CLI tests.
- **Complete CLI workflow.** Record, validate, import, summarize, and post PR comments from trace files.
- **Quality checks.** Structural validation, quality warnings, and a compact review checklist help reviewers judge agent runs quickly.
- **New demo GIF.** The refreshed demo shows the v1.0.0 CLI and Web UI workflow, including record, summarize, compact summaries, and trace import.
- **30 tests.** The CLI test suite covers happy paths, error paths, summary rendering, compact output, adapters, and version reporting.

## What's in v1.0.0

### Web UI

- Interactive action timeline
- Run list with status, trust score, branch, and duration
- Action detail panel with evidence notes
- Diff and command output panels
- Drag-and-drop trace import

### CLI

- `record` wraps any shell command into an AgentScope trace
- `validate` checks trace structure and quality warnings
- `import-jsonl` converts generic line-delimited agent logs
- `import-session` imports common Claude/Codex-style session exports
- `summarize` renders Markdown for PR review
- `--version` and `-V` print the AgentScope CLI version

### Trace Quality

- Structural trace validation
- Quality warning for edits without verification
- Quality warning for failed tests without later recovery
- Quality warning for high-risk edits without evidence notes
- Compact review checklist with Code changes, Verification, Failures recovered, and High-risk evidence

### PR Reviews

- Local dry-run preview with `summarize --dry-run`
- GitHub Actions live PR comments
- Hidden marker deduplication so repeated workflow runs update the same comment
- Compact mode with `summarize --compact`
- Omitted action counts with type breakdown for long traces

### Adapters

- Generic JSONL adapter
- Session JSON adapter for Claude/Codex-style tool-call exports

### Testing

- 30 CLI tests
- Node built-in test runner
- CI integration for lint, build, and trace validation

### Docs

- Published JSON Schema at `docs/trace-schema.json`
- Adapter roadmap and guides
- Session JSON guide
- Release checklist and roadmap
- Refreshed launch copy for HN, Reddit, and V2EX

## What's next

- Native Claude Code / Codex adapters
- Timeline search and filtering
- Execution graph for read/edit/verify relationships
- VS Code extension
