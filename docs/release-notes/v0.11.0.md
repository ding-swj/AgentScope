# AgentScope v0.11.0

AgentScope v0.11.0 is a CLI usability release. It adds a built-in version flag so users can report the exact AgentScope CLI version when filing bugs.

## Highlights

- **CLI `--version` flag.** `npm run agentscope -- --version` prints the AgentScope CLI version and exits.
- **Short version flag.** `npm run agentscope -- -V` prints the same version output.
- **Better bug reports.** The bug report template asks for "CLI version"; users now have a direct command to answer that question.
- **CLI test coverage.** 27 tests now cover the version flag plus existing smoke and error paths.

## Try it

```bash
npm run agentscope -- --version
npm run agentscope -- -V
```

Expected result:

```text
AgentScope CLI v0.10.0
```

## Why this matters

Small CLI affordances make support easier. When someone reports a validation, import, or PR summary issue, the first question is often which CLI version they used. The new version flag makes that answer copy-pasteable and keeps issue reports more actionable.

## Known limitations

- **Hardcoded version.** The CLI version is a hardcoded string and does not read `package.json`; release prep must update it manually when needed.
- **`-V` is only a short alias.** It is equivalent to `--version` and does not add extra metadata.
- **No package version coupling.** `package.json` remains at `0.0.0` and is not used for release tracking.
