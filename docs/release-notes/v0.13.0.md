# AgentScope v0.13.0

AgentScope v0.13.0 is the final PR summary polish release before v1.0.0. It makes long summaries easier to scan by showing omitted action counts by type and adds a compact mode for repeated PR review.

## Highlights

- **Omitted action type breakdown.** Long summaries now show which action types were omitted, for example `...and 21 more actions omitted (21 read_file)`.
- **Compact summary mode.** `summarize --compact` reduces the Verification section to one line per command or test action.
- **Shorter repeated PR comments.** Compact mode keeps reviewer-facing comments easier to re-read across repeated workflow runs.
- **PR Comment Improvements complete.** Roadmap item #8 now has its core checklist, omitted-count, and compact-comment work checked off.
- **CLI test coverage.** 30 tests now cover regular summaries, compact summaries, and omitted action counts by type.

## Try it

```bash
npm run agentscope -- summarize --input examples/auth-fix.trace.json --dry-run
npm run agentscope -- summarize --input examples/auth-fix.trace.json --compact --dry-run
```

The compact output keeps Verification to one line per action:

```markdown
### Verification

- **run_command:** `npm test -- session.test.ts` (6 lines)
- **test_failed:** `Failure isolated to refresh fixture` (0 lines)
- **test_passed:** `npm test && npm run typecheck` (6 lines)
```

## Why this matters

PR summary comments should be useful every time a workflow runs, not just the first time. Type-aware omitted counts preserve useful signal when a trace is long, while compact mode keeps verification evidence visible without flooding the PR conversation.

## Known limitations

- **Artifact links remain planned.** PR summaries still do not link uploaded trace artifacts.
- **Compact mode summarizes output only.** Reviewers can still use the full non-compact summary when they need expanded command output.
- **Action table limit remains fixed.** The summary still shows up to 20 actions before omitting the rest.
