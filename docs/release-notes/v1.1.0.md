# AgentScope v1.1.0

AgentScope v1.1.0 is a PR summary completion release: roadmap #8 is now fully closed.

## Highlights

- **CI artifact link.** When `GITHUB_RUN_ID` is set, `summarize` adds a link to the GitHub Actions run at the bottom of the PR summary.
- **Roadmap #8 complete.** PR Comment Improvements now includes the review checklist, artifact link, omitted action type breakdown, and compact mode.
- **32 CLI tests.** The test suite now covers the artifact-link behavior in both CI-like and local dry-run environments.

## Try It

```bash
npm run agentscope -- summarize --input examples/auth-fix.trace.json --dry-run
npm test
```

Local dry-run output does not show an artifact link. In GitHub Actions, AgentScope uses `GITHUB_REPOSITORY` and `GITHUB_RUN_ID` to link back to the workflow run.

## Why This Matters

From v0.9.0 through v1.1.0, AgentScope tightened the PR review flow around four pieces:

- Review checklist in v0.9.0
- Omitted action type breakdown in v0.13.0
- `--compact` summaries in v0.13.0
- CI artifact link in v1.1.0

Together, these let reviewers assess an agent run from the GitHub comment without immediately leaving the PR.

## Known Limitations

- Artifact links only appear in GitHub Actions CI environments. Local `--dry-run` output intentionally omits them.
- Both `GITHUB_REPOSITORY` and `GITHUB_RUN_ID` must be present before the link is rendered.
