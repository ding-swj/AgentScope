# AgentScope v0.10.0

AgentScope v0.10.0 is a CLI hardening release. It extends CLI error-path test coverage from 21 to 26 tests, locking in user-facing failures for record, summarize, and import-session flows.

## Highlights

- **Five new CLI error-path tests.** `npm test` now covers 26 CLI smoke and error-path cases.
- **Record missing command.** `record` now has a test for the no-command error path.
- **Summarize missing input.** `summarize` now has a test for missing `--input`.
- **Summarize empty marker.** `summarize` now has a test for empty `--marker` values.
- **Import-session missing file.** `import-session` now has a test for missing input files.
- **Import-session malformed JSON.** `import-session` now has a test for invalid JSON input.
- **Roadmap accuracy.** Trace Quality Checks are now marked as shipped since v0.8.0.

## Try it

```bash
npm test
```

Expected result:

```text
tests 26
pass 26
fail 0
```

## Why this matters

AgentScope's CLI is the path most users and CI workflows touch first. Error-path tests keep the failure behavior stable when the CLI grows or gets refactored, so missing arguments, invalid files, and malformed session exports continue to produce clear, predictable messages.

## Known limitations

- **Unknown summarize options are not covered yet.** The CLI still does not have a dedicated test for unsupported `summarize` flags.
- **Record spawn errors are not covered yet.** The test suite covers missing, passing, and failing recorded commands, but not process spawn failures.
- **No new runtime behavior.** This release hardens tests and roadmap documentation; it does not add a new CLI command or UI feature.
