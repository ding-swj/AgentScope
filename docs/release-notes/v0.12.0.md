# AgentScope v0.12.0

AgentScope v0.12.0 is a patch release for the CLI version string and documentation. It fixes the v0.11.0 release metadata so the version flag, README, release notes, and release checklist agree with the current project state.

## Highlights

- **Correct CLI version output.** `npm run agentscope -- --version` now reports `AgentScope CLI v0.11.0` instead of the stale v0.10.0 value.
- **README test count fixed.** The README now shows 27 CLI smoke and error-path tests passing.
- **Release checklist hardened.** The release checklist now reminds maintainers to verify `CLI_VERSION` before tagging.
- **Exact version test.** The `--version` test now uses an exact match so future releases cannot silently drift.

## Try it

```bash
npm run agentscope -- --version
npm test
```

Expected result:

```text
AgentScope CLI v0.11.0
tests 28
pass 28
fail 0
```

## Why this matters

The CLI version flag is only useful if it reports the right value. This release closes the loop after v0.11.0 by correcting the hardcoded version string and adding checklist/test coverage so the same release-prep miss is easier to catch next time.

## Known limitations

- **Hardcoded version remains.** The CLI version is still a hardcoded string and does not read `package.json`.
- **Release discipline required.** Future releases still need a manual version bump until version metadata is automated.
- **Patch-only release.** This release does not add a new user-facing command beyond the already shipped `--version` and `-V` flags.
